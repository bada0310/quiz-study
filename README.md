# 🚀 실시간 노션 퀴즈 쇼 (Real-time Notion Quiz Platform)

스터디원들과 실시간으로 즐길 수 있는 **웹소켓(WebSocket) 기반의 인터랙티브 퀴즈 웹사이트**입니다.
가장 익숙한 문서 툴인 '노션(Notion)'을 데이터베이스(DB)로 활용하여, 노션에 문제를 적어두기만 하면 자동으로 퀴즈 쇼 세팅이 완료됩니다.

## ✨ 주요 기능 (Key Features)
* **📝 노션 DB 자동 연동:** `update_notion.py` 실행 한 번으로 노션 표의 문제, 정답, 해설을 JSON 형태로 긁어옵니다.
* **⚡ 실시간 웹소켓 통신:** 방장(출제자)과 참가자(응시자) 간의 화면이 실시간으로 동기화됩니다.
* **📊 출제자 실시간 모니터링:** 응시자가 어떤 답(O/X, 주관식)을 골랐는지 방장 화면에 실시간으로 집계되어 표시됩니다. (중복 제출 방지 및 취소 기능 포함)
* **🏆 종합 누적 랭킹 보드:** 퀴즈가 끝난 후, 서버가 자동으로 채점한 결과를 바탕으로 전체 스터디원의 점수를 층층이 쌓인 막대그래프(Stacked Bar Chart)로 시각화하여 보여줍니다.

---

## 🛠️ 기술 스택 (Tech Stack)
* **Backend:** Python, FastAPI, WebSockets, Uvicorn
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Chart.js
* **Database/API:** Notion API (Integration)

## 🛠️ 설치 및 실행 방법

### 1. 프로젝트 다운로드 및 라이브러리 설치
```bash
git clone [여기에_본인의_깃허브_주소_입력]
cd testfolder
python -m pip install -r requirements.txt
```

### 2. 환경 변수 (.env) 세팅
프로젝트 최상단 폴더에 `.env` 파일을 생성하고, 본인의 노션 API 토큰과 페이지 ID를 입력합니다.
```env
NOTION_TOKEN=secret_여기에_토큰_입력
NOTION_PAGE_ID=여기에_32자리_페이지_ID_입력
```
*(💡 팁: 페이지 ID는 노션 공유 링크 주소의 맨 끝 32자리 문자/숫자 조합입니다.)*

### 3. 노션에서 최신 문제 가져오기
```bash
python update_notion.py
```

### 4. 실시간 서버 실행
```bash
uvicorn main:app --reload
```
실행 후 브라우저에서 `http://127.0.0.1:8000` 으로 접속하세요!

> **🌍 외부 사람들과 공유하려면?**
> * **같은 와이파이:** 서버를 켤 때 `uvicorn main:app --host 0.0.0.0 --port 8000 --reload` 로 실행 후, 사람들에게 `http://내IP주소:8000` 링크를 공유합니다.
> * **원격 환경(다른 IP):** 서버를 켠 상태에서 터미널 창을 하나 더 열고 `ngrok http 8000`을 입력하여 생성된 외부 링크를 공유합니다.

---

### ⚡ (보너스) 원클릭 실행 파일 만들기 (`start.bat`)
윈도우 환경에서 더블클릭 한 번으로 전체 실행을 돕는 마법의 파일을 만들 수 있습니다. 
프로젝트 폴더 내에 `start.bat` 이라는 파일을 만들고 아래 코드를 적어두세요.

```bat
@echo off
echo 필요한 라이브러리를 설치합니다...
python -m pip install -r requirements.txt

echo.
echo 노션에서 최신 문제를 가져옵니다...
python update_notion.py

echo.
echo 실시간 퀴즈 서버를 시작합니다!
uvicorn main:app --reload
pause
```
